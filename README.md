> Landing page para a **Dra. Dafnny Anny**, especialista em facetas e estética dental.
> Projeto real, feito para cliente, com HTML, CSS e JavaScript puros, sem frameworks.

**🔗 Site no ar:** https://dra-dafnny-anny.vercel.app

---

## 📸 Visão geral

O objetivo do site é transmitir **confiança** e levar o visitante a agendar uma avaliação. A mensagem principal é *"Não é só estética. É autoestima."*: transformar sorrisos preservando os dentes naturais.

## 🧭 Seções

| Seção | Conteúdo |
|---|---|
| **Facetas** | Apresentação do serviço principal |
| **Outros Serviços** | Demais tratamentos oferecidos |
| **Feedbacks** | Depoimentos de pacientes |
| **Sobre** | Quem é a Dra. Dafnny Anny |
| **Perguntas Frequentes** | Dúvidas comuns em formato de acordeão |
| **Rodapé** | Contato, Instagram e mapa do consultório |

## ✨ Funcionalidades

- Animações acionadas pela rolagem com **GSAP + ScrollTrigger**
- **FAQ em acordeão**: as respostas abrem e fecham ao clicar
- Agendamento direto pelo **WhatsApp** e link para o **Instagram**
- **Mapa** incorporado do Google Maps
- Ícones com **Font Awesome**
- Layout **responsivo** para celular, tablet e desktop
- `meta description` preenchida, para o site aparecer melhor no Google

## 🚀 Como rodar

Não precisa instalar nada:

1. Clone ou baixe o repositório.
2. Abra o `index.html` no navegador, ou use a extensão **Live Server** do VS Code.
